{# Embeddable Urban Digital Twin console. Usage - set twin_variant to compact, embedded or page, then include this file: set twin_variant = 'compact' include "partials/twin_console.html" (Written without Jinja delimiters on purpose: Jinja comments do not nest, so a literal example inside this block would end the comment early and leave the include live - which makes the partial include itself, forever.) The host page passes no data. City list, zones, camera positions and every layer come from GET /api/twin/... at runtime, so the same partial works on any page without the view having to know anything about the twin. Wrap it in a card carrying `twin-host-card`, which opts the card out of the global hover transform - a CSS transform on any ancestor of a MapLibre canvas breaks its pointer-to-map coordinate maths. #} {% set variant = twin_variant | default('embedded') %} {# MapLibre must exist exactly once per page. Loading a second copy silently replaces window.maplibregl and detaches every map already built from the first, with no console error. This guard injects it only if it is absent, so a host page that already loads it in wins. #}
